# JH Digital

Portafolio comercial independiente para JH Digital. Lanzamiento previsto: lunes 23 de noviembre de 2026, Quito.

## Desarrollo

Requiere Node.js 22.12+ o 24. Ejecutar `npm ci`, `npm run dev` y `npm run build`. Vite genera `dist/`; Vercel utiliza la configuración de `vercel.json`.

## Alcance

- React, Vite y TypeScript; estilos propios sin librerías visuales.
- Cuatro demos con capturas reales, enlaces y límites funcionales.
- JH Presencia desde $89; JH Negocio desde $249; mantenimiento opcional desde $20/mes, con entregables y exclusiones.
- Consulta mediante enlace a WhatsApp; el visitante decide enviar. Sin backend, analítica ni almacenamiento de datos del visitante en la aplicación.

- JH Reservas no se ofrece: falta desarrollo y validación funcional.
